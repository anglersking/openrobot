# OpenRobot

面向真实生活的开源机器人项目。

OpenRobot 不以“做一个看起来像人的机器人”为目标，也不追逐人形概念。我们从一套可制造、可维修、可复用的无刷电机机械臂开始，逐步把执行器、感知、控制、数据和软件系统拼成真正能在生活中工作的机器人。

> **从无刷机械臂开始，理解身体；从真实视频开始，理解动作；最终让机器人适应真实世界。**

## 项目愿景

做一套开放的机器人基础设施，让不同形态的机器人都能共享：

- 可靠且成本可控的无刷执行器与机械结构
- 可观测、可标定、可复现的控制系统
- 从真人视频学习动作，再转换到机器人关节、末端轨迹和力矩的通用方法
- 面向不同机器人形态的数据表示、映射和迁移工具
- 可落地的采集设备、仿真环境、训练流程和安全机制

机器人的身体不必固定为人形。轮式、履带式、双臂、移动操作平台，甚至为特定生活任务设计的专用形态，都应该能够接入同一套数据与控制基础设施。

## 核心路线

### 1. 从无刷机械臂开始

第一阶段聚焦无刷电机驱动的模块化机械臂，优先解决最基础也最重要的问题：

- 执行器：无刷电机、减速机构、编码器、驱动器和热管理
- 机械：关节模块、连杆、末端执行器和可维护结构
- 控制：位置、速度、力矩、阻抗和碰撞检测
- 工具链：标定、日志、诊断、仿真和硬件在环测试

机械臂不是最终产品，而是让我们先把“身体”做扎实的起点。

### 2. 用真实视频建立动作数据

我们计划使用已有的网络真人视频作为重要的数据来源，结合公开数据集、仿真数据和专用采集设备，建立可追溯的数据流水线：

```text
视频 → 人体/物体理解 → 动作表示 → 机器人约束 → 关节轨迹 → 力矩与接触估计 → 真机验证
```

这里的目标不是简单复制人的外形，而是提取动作背后的任务意图、时序、接触关系和动力学线索。

网络视频会存在视角、遮挡、帧率、版权和标注质量问题。因此，项目会明确记录数据来源、许可证和处理方式；对于不具备再分发权限的数据，只保存必要的特征、标注或指纹，不直接打包传播原始内容。

### 3. 让动作适应不同的身体

同一个“拿起杯子”的动作，映射到不同自由度、不同关节布局、不同工作空间和不同负载的机器人时，不能只做角度复制。

OpenRobot 将围绕以下中间表示构建转换层：

- 任务与技能：拿取、放置、开门、清洁、递送等
- 末端轨迹：位置、姿态、速度和接触事件
- 关节状态：位置、速度、加速度和可行域
- 动力学信息：力矩、接触力、摩擦和负载
- 约束信息：关节限位、碰撞、稳定性、能耗和安全边界

最终目标是：**看视频，理解动作；换一个身体，仍然能够执行。**

## 系统组成

仓库按机器人系统的主要边界组织：

| 目录 | 方向 |
| --- | --- |
| `hardware` | 机械结构、执行器、驱动器与电子硬件 |
| `robot` | 机器人本体、关节和末端执行器 |
| `midware` | 通信、消息、设备抽象和运行时中间件 |
| `algorithm` | 运动学、动力学、规划、控制和状态估计 |
| `model` | 机器人模型、动作表示和跨形态映射 |
| `daq` | 数据采集设备、同步、标定和数据记录 |
| `data_analysis` | 数据清洗、标注、质量评估和可视化 |
| `train` | 模型训练、评估和部署流程 |
| `simulation` | 仿真、回放和硬件在环测试 |
| `state_machine` | 技能编排、任务状态机和故障恢复 |
| `app` | 面向使用者的应用和操作界面 |
| `visual` | 视觉感知、人体姿态和场景理解 |
| `test` | 单元、集成、仿真和真机测试 |
| `devops` / `docker` | 构建、部署和开发环境 |

## 数据闭环

项目会优先建设一套专用数据采集设备，而不是凭经验“拍脑袋”决定数据格式。采集设备和协议至少需要支持：

- 多相机、深度、音频和机器人状态的统一时间戳
- 关节位置、速度、电流、力矩、温度和故障状态
- 末端六维力/力矩、接触事件和环境状态
- 采集标定、设备配置、数据版本和实验元数据
- 原始数据、处理数据、标签和评估结果的可追溯关联

每一条数据都应该能回答：在哪里采集、用什么设备、什么版本处理、经过哪些转换、在什么机器人上验证。

## 开发阶段

### 阶段 0：基础设施

- 明确数据格式、坐标系、时间同步和版本规范
- 建立开发、仿真、日志和测试环境
- 完成第一版无刷关节原型与安全急停链路

### 阶段 1：无刷机械臂

- 完成模块化关节、机械臂和末端执行器
- 实现位置/速度/力矩/阻抗控制
- 完成标定、碰撞检测、回放和硬件在环测试

### 阶段 2：数据采集与动作表示

- 发布专用采集设备的硬件和软件设计
- 建立视频到人体动作、物体关系和接触事件的处理流程
- 发布第一版机器人动作中间表示和数据集工具

### 阶段 3：跨形态迁移

- 将同一技能映射到不同机械臂和移动操作平台
- 结合动力学约束生成关节轨迹与力矩参考
- 在仿真和真机上进行可重复评估

### 阶段 4：生活场景验证

- 从低风险、可量化的生活任务开始
- 建立失败记录、人工接管和安全回退机制
- 以长期稳定性、可维护性和实际完成率作为主要指标

## 安全与责任

这是一个会与真实世界交互的项目，安全优先于演示效果。所有真机功能都应具备限位、急停、低速调试、碰撞保护、权限控制和日志记录。未经充分验证的控制策略不得直接用于高风险环境。

项目中的网络视频和衍生数据必须遵守适用的版权、隐私、平台条款和数据保护要求。贡献数据时，请提供来源、许可证、处理步骤和可再分发范围；不要提交未经授权的个人敏感信息。

## 参与方式

项目目前处于早期设计和原型阶段，欢迎以下类型的贡献：

- 无刷关节、机械结构、驱动和嵌入式开发
- 机器人运动学、动力学、控制和规划
- 视觉、人体动作估计、视频理解和跨形态迁移
- 数据采集设备、数据格式、标注工具和质量评估
- 仿真、测试、文档和真实生活场景验证

提交代码、硬件设计或数据前，请先阅读对应目录的说明，并在 Issue 中说明目标、测试环境和已知限制。

## English summary

OpenRobot is an open-source effort to build practical robots for everyday life. We start with modular brushless-motor arms, build a reliable body and data pipeline, learn skills from real human videos, and transfer those skills to robots with different morphologies. The project focuses on useful robots, measurable experiments, safety, reproducibility, and open infrastructure—not humanoid marketing.
